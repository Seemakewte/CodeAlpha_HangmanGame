
Hangman Game - Python

Project Description
Hangman is a simple text-based word guessing game
developed using Python.

The computer randomly selects a word, and the player
tries to guess it one letter at a time.

The player gets a maximum of 6 incorrect attempts
to guess the correct word.

 Features
- Random word selection
- Maximum 6 incorrect attempts
- Letter-by-letter guessing
- Input validation
- Prevents repeated guesses
- Win and lose conditions
- Console-based interface

Technologies Used
- Python
- Random Module
- While Loop
- For Loop
- Conditional Statements
- Lists and Strings

 How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

```bash
python hangman.py
```
